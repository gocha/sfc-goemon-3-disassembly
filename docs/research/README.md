# Research Notes

This directory contains working notes for ongoing reverse-engineering investigations.

The information here may be incomplete, tentative, or incorrect. When possible, distinguish between:

- **Confirmed** facts supported by code or experiments
- **Hypotheses** that still need verification
- **Unknowns** and open questions
- **Next experiments** or investigation steps

Notes may be written in either English or Japanese. Japanese is welcome when it makes investigation, discussion, or documentation easier.

These notes are intended to preserve intermediate findings and investigation history until they are sufficiently understood to be reflected in source code, symbols, comments, or more permanent documentation.
